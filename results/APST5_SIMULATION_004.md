# APST5-SIM-004: Multimodal Redundancy Stress Test

**Status:** computational robustness test.

APST5-SIM-003 showed that concurrent pupil + smooth-pursuit sensing can move the duration-information frontier in a broad surrogate sensitivity grid.

Its cleanest information calculation treated the channels as conditionally independent.

Real ocular channels will overlap.

APST5-SIM-004 therefore asks:

> **How much of the second channel's information can be redundant before the temporal-compression result disappears?**

## Redundancy envelope

For efficient state information Jp from pupil and Jg from pursuit, define:

J_joint(kappa) = max(Jp, Jg) + kappa * min(Jp, Jg),

where 0 <= kappa <= 1.

Interpretation:

- kappa = 1: all weaker-channel information is incremental;
- kappa = 0.5: only half is incremental;
- kappa = 0: complete redundancy; the joint system is no better than the stronger channel.

This is deliberately more conservative than assuming additivity.

It is not an exact covariance model. It is an information-overlap stress envelope.

## Experiment

The same 80-cell physiological/device sensitivity grid from APST5-SIM-003 is reused:

- five pursuit state-effect magnitudes;
- four response-slowing assumptions;
- four gaze-noise levels.

For each cell, the pursuit frequency is optimized on a design population and evaluated on fresh nuisance/state-effect draws.

Comparator:

IG_5s,pupil-only = 0.392970 nats.

Reproduce with:

python experiments/multimodal_redundancy.py

## Interpretation rule

The useful result is not that multimodality is mathematically guaranteed to help.

At kappa = 0, it cannot provide a fusion bonus by definition.

The useful question is the **break-even incremental-information fraction** required for a 2–3 second concurrent scan to outperform the five-second pupil-only reference across a meaningful portion of the uncertainty grid.

The reproduced numeric table is generated by CI and should be copied here only from the committed run output.

## Human implication

A human phone experiment should estimate conditional information directly, conceptually:

I(State; Gaze | Pupil, History),

rather than assuming pupil and gaze are independent.

The multimodal architecture is supported only if gaze adds held-out state information after conditioning on pupil response and personal history.
