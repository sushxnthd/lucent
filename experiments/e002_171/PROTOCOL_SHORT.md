# E002-171 frozen protocol

Source: EyeBlink8 annotations, nominal 30 fps. Treat blink ID zero as a valid blink. Five-second windows require 150 consecutive frames. Exclude incomplete windows and uncertain event starts. Compare observed empty windows with the recording-stratified conditional Poisson occupancy expectation. The predeclared discrepancy threshold is ten percentage points and a Monte Carlo p-value of at most 0.01. Results cannot establish fatigue or physiological pupil-waveform recovery.
