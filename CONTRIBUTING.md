# Contributing

Lucent is currently a focused research project. Contributions are most useful when they increase falsifiability, reproducibility, or robustness.

Good contributions include:

- stronger leakage tests;
- better grouped-split utilities;
- baseline implementations;
- robustness / calibration evaluation;
- literature corrections;
- reproducible analyses of public drowsiness datasets;
- negative results that invalidate an assumption.

Please avoid adding product UI, speculative medical claims, or benchmark numbers without a reproducible experiment.

## Research changes

For any change that affects a reported result:

1. state the hypothesis;
2. identify the dataset / cohort;
3. identify the exact split;
4. add or update tests;
5. record the experiment configuration;
6. separate exploratory changes from confirmatory results.

The fastest way to make Lucent look better is not a larger model. It is a result that is harder to fool.
