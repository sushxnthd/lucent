# E002-282 conditional three-patch shutter boundary

SCIENCE: A normalized three-patch contrast cancels unknown common positive affine gain and offset under stable co-exposed references. A two-patch intensity ratio does not cancel additive offsets. With known open/closed normalized contrast delta, independently bounded per-patch error eta, and independently calibrated minimum reference separation Dmin, binary-state observation sets are disjoint exactly when Dmin*delta > 4*eta. Under rectangular exposure T <= frame period P, illumination bounds 0<m<=L<=M, and framewise unconstrained affine photometry, define q=4*eta/(Dmin*delta). If q>=1 no event duration guarantees separation. Otherwise lambda=q*M/(m*(1-q)+q*M) and the sharp worst-phase event duration boundary is dcrit=P-T+2*T*lambda. Only d>dcrit guarantees a separable frame under all event phases.

SCIENCE proof: For latent normalized eye states q0<q1 in [0,1], compare ideal triples (a0*q0+b0,b0,a0+b0) and (a1*q1+b1,b1,a1+b1), with a0,a1>=Dmin. If u=a0-a1>=0, the third minus first difference is (1-q0)u+a1*(q1-q0)>=Dmin*(q1-q0). If u<0, minus the first difference is q1*(-u)+a0*(q1-q0)>=Dmin*(q1-q0). Centering the unknown offset gives minimum infinity-norm distance Dmin*(q1-q0)/2, attained at equal minimum gains. Two error balls of radius eta intersect exactly at/below 4eta. Exposure integration with bounded illumination yields minimum weighted overlap m*lambda/(m*lambda+M*(1-lambda)); phase-worst overlap is clip((d-(P-T))/(2T),0,1).

PRODUCT: Evaluate three co-row patches only when stable references, gain/noise/exposure and spatial illumination residual are independently calibrated. Reject low-contrast cases, saturation, local photometric drift, or unknown shutter. No anatomical pupil, eyelid velocity, or fatigue inference.

Evidence: 40960 synthetic phase decisions across six predeclared cases, independent 8192-phase checker and five independent local SciPy linear programs. No human RGB/reference data or real-device calibration. Field-level novelty unverified. This is a conditional set-membership application of established photometric invariance and shutter geometry, not a new general mathematical theorem.
