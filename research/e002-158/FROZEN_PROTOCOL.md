# E002-158 frozen protocol (2026-10-13)
Active question: can RGB pixels distinguish pupil from immediate nonpupil eye pixels well enough to support an eventual 5-second RGB/reference pupil waveform measurement? This experiment measures local photometric separability, not physiological waveforms.
Dataset: original JPEG and PNG masks, Zenodo record 20492528, ZIP SHA256 049df72454682c1c77c50c8236bb607919a6e333528bc2b89c567b625e459700. Hash-sort paired JPEG paths, skip first 960, score next 480 eligible. No participant IDs assumed. Masks are oracle evaluation labels only. Do not redistribute images.
Eligibility: red>=128 pupil, red or green>=128 visible eye, pupil >=16 pixels, eye>=64 pixels, pupil/eye radius ratio<0.9; local ring is 4-pixel pupil dilation excluding pupil and outside-eye pixels; >=16 ring pixels.
Scalar: per-image Mann-Whitney AUC discriminating pupil vs local ring using negative RGB luminance; compare negative R, G, B, and negative high-pass luminance (Gaussian sigma=5). Permutation placebo uses seed 1582026. Report median, p10, fraction AUC>=0.8, group medians, brightness quartiles and AUC reversals.
Frozen gates: G0 >=300 eligible and >=10 filename groups with source hash verified; G1 median luminance AUC>=0.8; G2 p10 AUC>=0.65; G3 >=75% images AUC>=0.8; G4 shuffled-label mean AUC within 0.03 of 0.5; G5 all groups with >=10 samples median AUC>=0.55; G6 RGB/tracker waveform UNTESTED. No gate retuning.
SCIENCE: tests whether local RGB photometric discrimination is plausible under favorable oracle evaluation; not segmentation, iris diameter, or synchronized physiology. PRODUCT: a possible contrast-quality warning flag only if stable; no validated physiological measurement. Strongest confounds: illumination, eyelashes, dark iris, JPEG artifacts, gaze, crop. Kill intermediate kernel if no source-robust separability; preserve negative results.
Ultimate kernel: ordinary RGB pupil/full-iris ratio versus independently timed tracker pupil waveform over ~5 seconds; prospective participant/device heldout correlation, lag, amplitude and NRMSE at useful coverage, with brightness/geometry controls. Success requires unseen-condition prediction and independent checker. No fatigue claim before that.
