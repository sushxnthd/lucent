# Frozen prospective human validation protocol
Use native, non-downsampled ordinary RGB with measured frame start, row readout and shutter duration, concurrent synchronized >=250-fps trustworthy eye-reference aperture. Define closure at 50% participant-normalized aperture (30% and 70% sensitivity). Preassign disjoint participant/device train/validation/untouched test. Train only on training strata to bound rowwise nuisance-projected contrast rho_i, clock uncertainty u_i and RGB error epsilon. Before touching final holdout, freeze one predicted survival/failure boundary crossing for a new participant/device/lighting regime. Compare two reference-defined closure bouts against a specific merged-bout alternative with same outer endpoints. Report reference-confirmed sensitivity, specificity, false certification and interval coverage, stratified by gaze, glasses, lighting and device. Strongest controls: geometry-only, brightness-only, missingness-only, temporal smoothness, uncorrected RGB, randomized shutter phase and nuisance-only counterexamples. Reject positive transfer if calibration fails, if held-out certifiable events remain invisible, if strongest controls match it, or if uncertainty coverage fails. Do not infer physiological lag from uncalibrated timestamps. No paired human test performed in this run. Dataset/access work is limited to two substantive blocked attempts per route, then switch to theory/simulation/another route.
