# E002-398 pre-execution correction: blind identifier secrecy

The frozen protocol's public deterministic seed would allow an annotator to brute-force the 40 known pair/arm combinations and reconstruct event/control status. This is a blinding failure discovered **before any E002-398 source frames were decoded or analyzed**. Preserve the original protocol as an audit artifact, but replace its public seed with a fresh cryptographically random 256-bit secret per generation, stored only in the **local private linkage**. IDs are HMAC-SHA256(secret, participant + pair index + arm) truncated to 20 hex characters; public manifests contain no key, pair index, arm, source frame ID, timestamp or clip order. Randomized public row order must not reveal pairings. All fixed source selection, image crop, annotation requirements and checks C1–C5 are unchanged. Different generations have different IDs, but selected frame-content SHA256 hashes and descriptive statistics must be reproducible. No claim of participant holdout or physical ground truth is introduced.
