# E002-695 — Blind prediction freeze before high-speed reference inspection

**Tier:** executable prospective validation infrastructure; no physical or human observations.

Run `python research/observability/e002_695_blind_prediction.py input.csv frozen.json` on the low-rate acquisition/calibration table **before** inspecting any high-rate reference labels. The script refuses inputs containing reference minima/labels or previous phone decisions, rejects duplicate IDs, uses exact decimal arithmetic, fails closed on missing/invalid/unverified inputs, refuses to overwrite an existing freeze, and prints a SHA-256 digest of the frozen JSON. Archive the input, output, digest, software commit, acquisition metadata, and independently signed custody record in separate immutable storage. A SHA-256 digest is tamper-evidence only if its earlier existence is independently witnessed; a `provenance_verified=true` CSV field is merely an operator assertion, **not** authenticated provenance. Velocity evidence IDs are also references, not proof of a physiological ceiling.

**Frozen decision:** Given aperture intervals [a,A], [b,B], closure threshold c, justified velocity ceiling V and authenticated blind-gap upper bound h, set a*=max(a,b−Vh), b*=max(b,a−Vh). If a*>A or b*>B abstain; otherwise lower=max(0,(a*+b*−Vh)/2), and exclude closure only if lower>c. The input must represent calibrated *instantaneous* anatomical endpoint intervals. Do **not** enter exposure-averaged pixel/landmark readings; E002-694 requires a different certificate for ideal exposure means. Rolling-shutter/clock/exposure uncertainty must already be conservatively incorporated in h and aperture intervals. Missing timing bounds imply abstention, not a nominal-fps estimate.

**Local smoke test:** Three constructed CSV rows produced one exclusion, one possible-closure abstention and one unverified-provenance abstention. This checks code execution only, not physical correctness. No human data were accessed, no velocity bound independently established, and no real reference comparison occurred.
