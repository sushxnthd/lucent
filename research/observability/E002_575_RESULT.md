## Result: generated optical test-pattern video, not human data

On a **synthetic** 95-Hz 57-frame FFV1 video generated by ffmpeg (96 × 64 pixels), the private packet builder extracted two disjoint 19-frame native-index windows (0–18, 38–56). It generated **38 native-geometry decoded PNGs for each of two simulated reviewer destinations**, with equal per-frame SHA-256 digests across destinations and a separate owner-only native-index/source-hash audit. The reviewer payloads contain no participant/video identity, source hash, or native index; their anatomical fields remain explicitly UNREVIEWED.

All **13 local Python adversarial tests passed**. They exercised native-frame extraction, identical A/B packets, geometry, source substitution, post-manifest video mutation, incorrect declared frame count, prefilled anatomical labels, missing clips, overlapping windows, existing output, symlinked video source, nonmonotonic timestamps, variable dimensions, invalid PNG, and absent source records. Tests were run with the local ffmpeg and ffprobe executables; this is not yet independent hosted verification.

The implementation checks the original video SHA-256 **before and after** decoding; verifies every decoded frame count against the independently supplied manifest; requires strictly increasing container presentation timestamps and fixed decoded dimensions; rejects overlapping/out-of-range source windows; creates private output with restrictive file modes; and cleans partial output on failure. It does **not** claim optical clock authentication: monotonic container timestamps can be synthetic or fabricated.
