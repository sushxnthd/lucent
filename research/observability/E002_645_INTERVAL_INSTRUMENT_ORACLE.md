# E002-645 | Conservative interval oracle for physical shutter trials (2026-11-04 UTC)

## New enforceable result
The E002-644 acquisition protocol is now accompanied by a deterministic interval oracle, `e002_645_interval_instrument_oracle.py`. For each reference-timed LED pulse P and every relevant camera exposure E_i, with independently certified uncertainty on both start and end times, a **guaranteed miss** is valid only when the latest possible pulse end is no later than the earliest possible exposure start, OR the earliest possible pulse start is no earlier than the latest possible exposure end, **for every exposure**. Equality is treated as zero overlap. A **guaranteed positive temporal intersection** requires one exposure for which the latest possible pulse start is strictly earlier than the earliest possible exposure end AND the earliest possible pulse end is strictly later than the latest possible exposure start. All remaining cases abstain.

This is an interval-geometric result, not a claim that an intersection will be detected. Integrated photons, gain, saturation, ISP, compression, rolling shutter, exposure tails, sensor response and an independently certified visibility floor determine whether an intersection can create a detectable signal. The program deliberately names the positive class GUARANTEED_INTERSECTION rather than VISIBLE.

## Adversarial consequence
A single additional relevant row exposure can invalidate a guaranteed-miss claim. Missing or inconsistent time intervals, missing clock certification, missing exposure certification, or absent exposure windows force ABSTAIN. Missing SNR certification prohibits even the positive intersection output in this deliberately restrictive implementation. This control must be evaluated on physical LED/photodiode captures, not synthetic observations generated by the same oracle.

## Execution and evidence tier
Nine deterministic synthetic assertions are included as a standalone Python self-test. Their successful execution has **not** been independently verified in this commit. No instrument traces, high-frame-rate human eyelid annotations, independent physiological velocity or acceleration ceilings, or held-out human predictions were acquired. The implementation is not a camera driver or an authenticated certificate verifier; caller-supplied booleans are not trust evidence. The geometric result applies only to one shared certified clock and exhaustive exposure windows.
