# E002-572 | Frozen optical-edge clock/shutter instrument challenge

2026-10-31. Primary kernel E002-371; existing branch and draft PR #26. Freeze before implementation. This is an **instrument-substitute test**, not a physical human observation or a physiological velocity estimate.

## Question and falsification target

Can a conservative, independently timed LED/photodiode edge protocol recover a feasible camera-to-reference clock map from *partially illuminated, raw-linear sensor exposures* without incorrectly accepting a grossly mistimed held-out edge? Does it reject an internally inconsistent calibration series instead of silently fitting a convenient least-squares line?

A rising optical edge at independently measured time t, integrated during an exposure [s,s+w], produces post-edge light fraction f=(s+w-t)/w only under a verified **linear radiometric response**, fixed shutter, known exposure integration and exactly one edge within the exposure. Hence s=t-w(1-f). A falling edge uses post-edge darkness fraction, not brightness. Independent uncertainties t±dt, f±df, w∈[wlo,whi] yield a conservative start interval [t-dt-whi(1-f+df), t+dt-wlo(1-f-df)], enlarged for row skew. Treat metadata camera timestamp c only as a clock coordinate, not authenticated exposure start; infer s=a+bc.

Freeze an exact convex-feasibility procedure in (a,b), with predeclared prior ranges. Each calibration edge imposes s_lo ≤ a+bc ≤ s_hi. Intersect all strips with the prior rectangle; empty intersection means CALIBRATION_REJECTED. Predict held-out exposure-start intervals from the entire feasible polygon; an independently measured held-out edge outside that envelope is CONTRADICTION, not a parameter-refitting opportunity. Do not silently drop outliers. No training on held-out events.

## Frozen synthetic fixtures

- Fixed shutter interval 3.95–4.05 ms, reference edge uncertainty 50 microseconds, linear post-edge fraction uncertainty 0.01, rolling-row bound ±30 microseconds.
- True affine clock a=12 ms, b=1.000020; calibration camera timestamps c=[0,10,20,30] seconds; f=[0.2,0.4,0.6,0.8]. Reference edges generated by t=a+bc+w(1-f), w=4 ms.
- Held-out c=40 seconds, f=0.5, independently generated t from same model: require CONSISTENT.
- Adversarial held-out reference edge delayed +10 ms: require CONTRADICTION.
- One calibration edge shifted +10 ms: require CALIBRATION_REJECTED, with no dropped sample.
- Invalid plateaus, saturation f≤0 or f≥1, nonpositive shutter, insufficient distinct timestamps, unbounded clock prior, or missing independent uncertainty: require INVALID_INPUT/ABSTAIN.
- A deliberately non-affine clock perturbation at one edge must be rejected if it exceeds frozen uncertainty; if not, report an honest failure.

## Scope and safeguards

This is not camera authentication: photodiode edges, exposure intervals, row readout, response linearity, plateau stability and raw pixel fractions must be physically measured and independently documented. Gamma-encoded or auto-exposed RGB must not be passed off as raw linear exposure fractions. Even a successful physical optical calibration does not establish an upper bound on human eyelid speed or reference sensitivity. All physiological claims remain ABSTAIN_UNCALIBRATED; production BLOCKED.

Evidence tiers: synthetic oracle tests and independent implementation checks first; hosted CI only if observed; physical timing captures remain zero until actually acquired. Stop synthetic timing refinement after this bounded instrument acceptance test and prioritize the existing E002-567 blinded human/physical protocol.
