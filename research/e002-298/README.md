# E002-298 Spectral quotient observability

Conditional linear RGB mixture analysis. With three calibrated independent color vectors, occupancy can be algebraically separated from scalar shading and one fixed-spectrum additive reflection. Rank loss gives an exact observational collision. Synthetic tests expose severe failure under colored reflections, channel drift, and preblur spatial shading. No human evidence; no field-level novelty. The full reproducibility package is available separately.
