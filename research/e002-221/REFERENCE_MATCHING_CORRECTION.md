# E002-221 reference matching correction
Initial E002-221 analysis selected the nearest tracker row and only then checked whether its pupil measurement was valid. This can spuriously reject an otherwise measurable video time when invalid tracker rows interleave with valid rows. The follow-up computes nearest **valid** reference timestamps independently for each eye, under the same fixed 75 ms tolerance and the same five prespecified browser-clock offset hypotheses. The original output is retained for auditing. Browser event time is still not independently verified camera exposure time. A passed coverage test is only a necessary, not sufficient, condition for waveform certification.
