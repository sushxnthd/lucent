# E002-313 — calibrated shutter occupancy

Under a known static edge/blur model and bounded within-exposure contrast ratio r=m/M, the complete RGB edge occupation profile yields sharp expectile bounds on the unweighted exposure-mean eyelid state. This is a conditional theoretical instrument result, not human validation.

For uniform weighted occupation on [0,1] with r=0.5, the sharp interval is [0.4142135624,0.5857864376], tighter than the scalar-only interval [1/3,2/3]. A width-0.6 profile shift is certifiably positive only above 0.10294372515. Exact smooth full-image counterexample has means 4/9 and 5/9 with identical pixels. Real-world photometric/gaze/blur calibration remains absent. Field novelty unproven.
