# Lucent E002-269 — Reference-blind waveform certification replay

**Active question.** Can a visible-RGB pupil/iris waveform, calibrated on training participants, pass frozen same-eye tracker-diameter correlation, amplitude, lag, NRMSE and nuisance gates on untouched participants **without using the reference to decide admission**?

- Signal/reference: normalized visible-RGB pupil/iris ratio versus same-eye independently synchronized eye-tracker diameter (mm).
- Frontier: E002-268 established reference-dependent admission and unverifiable source-hash defects in E002-267; this run replaces reference-selected scoring with reference-blind admission and a complete denominator.
- Scalar: fraction of all RGB-admitted windows satisfying *all* frozen gates; participant-bootstrap CI and admitted coverage reported separately.
- Strongest confound: optical/photometric scale drift plus outcome-dependent reference selection; unbounded clock offset remains a lag-identifiability confound.
- Decisive falsification: paired sessions with identical RGB and different reference amplitude must be admitted identically, with the low-amplitude mismatch counted as failure.
- Publishable threshold: >=8 untouched human participants, independently verified native-time same-eye reference and exposure clock, device/lighting/glasses holdouts, independent checker, mechanism prediction, prior-art audit.
- Product threshold: >=75% accurate RGB-admitted human windows at >=50% coverage, with all frozen waveform gates.
- Kill: three non-discriminating runs or repeated prospective human waveform failure; two blocked paths require a data-path switch.
